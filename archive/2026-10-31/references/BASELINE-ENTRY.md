# 基准入口应保留的行为

原服务器的启动脚本有固定安装路径和本地凭据文件引用，公开版不复制它。笔记本适配时保留这些已验证要求：

- 原生 Host 实际采用目标 profile，不能只核对父入口名称或继承的环境变量。
- 精确模型/effort 和 PTC 选择经目标原生模型接口实现，已有会话历史保留。
- 工作台账本保持单 Host 所有权；端口冲突明确拒绝，不杀不明进程或删除锁。
- TUI 上游安全重试可能回落普通 profile；Desktop 需独立验证自己的启动和恢复链。
- 凭据由目标本地原生服务或环境提供，不写入启动脚本和仓库。
- 退出与恢复遵循目标应用行为；Desktop 托盘行为不照搬 TUI 的 /exit 或 tmux。

这些是迁移检查项，不是可直接运行的跨平台启动器。
