# DSH runtime reference for a new host

This is an integration example, not an installed global rule or a transfer of the original host's permissions. The complete common working-principle reference is `v9.0.en.reference.md`. System/platform instructions and the current user's authorized task govern. Read required sources fully; an unavailable required text stops only the dependent operation.

Use the target DSH's native instruction loader and verify the effective preset, global/project-chain budgets and actual request context when delivery is material. A file path, hash, installed file or visible UI setting does not prove the model received the full text. Configuration edits do not hot-load an active generation.

Preserve existing authentication, conversations, workspace registrations and user changes. Use supported native model/effort, tool, Jobs, session and plugin interfaces. Record requested, accepted and observed effects separately when material. Do not import Codex control APIs or another host's provider, service or memory grant as DSH authority.

Before non-simple implementation, assess relevant installed and upstream solutions, then adapt only the justified gaps. Keep one writer per shared target, a usable recovery path, and verification of material acceptance. A worker completion, card review state, cancellation request, direct process exit or tool receipt is not interchangeable with settled Jobs or user acceptance. Reconcile uncertain effects before replay or ownership transfer.

Delegation requires a bounded objective, authoritative inputs, acceptance, write ownership, evidence and stop conditions under current authority. Reviewers remain read-only. Do not create persistent infrastructure, weaken isolation, expose a service, install account integration or change defaults merely to simulate a capability.

No memory or knowledge binding is supplied here. A target-specific adapter needs its own verified identity, ownership, data scope, source preservation and receipt contract before use. The original host's memory banks, accounts, datasets and writer are deliberately absent from the public edition.

Verify target operating-system behavior independently. Bash managed-range and Linux scope fixes do not establish PowerShell or Windows process-range support. Preserve unknown and failure states; test cancellation and restoration through the target's native runtime.
